PR: AUTH - FUNCT

Se implementa el inicio de sesión para usuarios con rol `user` y `admin`, diferenciando el flujo de acceso según los permisos asociados a cada perfil.

Además, para agilizar el avance del proyecto, se continuó con la implementación de funciones finales dentro de esta misma rama.

Para usuarios con rol `user`, el sistema muestra un menú interactivo con las siguientes opciones:

1. Consultar equipos disponibles.
2. Solicitar un préstamo.
3. Consultar préstamos existentes del usuario.

Para usuarios con rol `admin`, el sistema muestra un menú interactivo dividido en las siguientes áreas:

1. Administración de usuarios:
   1.1 Registrar un nuevo usuario.
   1.2 Administrar usuarios existentes.

2. Gestión de equipos:
   2.1 Registrar un nuevo equipo.
   2.2 Consultar equipos existentes.

3. Gestión de préstamos:
   3.1 Aprobar o rechazar préstamos.
   3.2 Consultar préstamos existentes.
   3.3 Registrar devoluciones.
